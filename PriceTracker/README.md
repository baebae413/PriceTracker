
# Price Tracker — первая версия

Личный Android-мониторинг цен без сервера.

Сейчас прототип поддерживает Подружку:
- добавление URL товара;
- запоминание цены;
- ручная проверка всех сохранённых товаров;
- определение: цена снизилась / выросла / не изменилась;
- локальная SQLite-база на телефоне.

## Сборка через GitHub Actions

1. Создайте пустой GitHub repository.
2. Загрузите все файлы проекта в него.
3. Откройте вкладку Actions.
4. Выберите `Build Android APK`.
5. Нажмите `Run workflow`.
6. После завершения откройте результат workflow и скачайте artifact `price-tracker-debug`.
7. Внутри будет `app-debug.apk`.

## Важно

Это ранний прототип. Парсер Подружки намеренно сделан простым и будет дорабатываться после проверки на реальном телефоне.
